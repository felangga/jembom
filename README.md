# Jembom

A retro multiplayer Bomberman game playable over **Telnet** — straight from your terminal, BBS-style.

> 🤖 This game is fully generated by [Claude](https://claude.ai) (Anthropic).

---

## About

Jembom is a real-time multiplayer Bomberman game that runs as a Telnet server. Up to 4 players can join a room and battle it out on a grid map. Place bombs, destroy blocks, blow up your enemies, and be the last one standing.

- No client installation required — just a Telnet connection
- Supports Unicode block art and ASCII fallback for older terminals
- Persistent leaderboard (wins, kills, walls destroyed)
- Global lobby chat
- CPU bots fill empty player slots

---

## How to Play

### Connect

```
telnet jembom.fly.dev 8888
```

Or locally (default port 2001):

```
telnet localhost 2001
```

### Login

Enter a username (4–8 characters). If the name is new, you will register with a PIN. If it already exists, you will be asked for your PIN to log in.

### Lobby Controls

| Key | Action |
|-----|--------|
| `↑` / `↓` | Select a room |
| `Enter` | Join selected room |
| `C` | Create a new room |
| `T` | Open chat |
| `ESC` | Exit chat |
| `Q` | Quit |

### In-Game Controls

| Key | Action |
|-----|--------|
| `W` / `A` / `S` / `D` or Arrow keys | Move |
| `Space` or `B` | Place bomb |
| `Q` | Quit to lobby |

## Leaderboard

Rankings are based on a score formula:

```
Score = (Wins × 100) + Walls Destroyed
```

The leaderboard shows: **Score / Wins / Kills / Walls Destroyed**

## Self-Hosting

### Requirements

- Go 1.21+
- SQLite (via `modernc.org/sqlite` — no CGO required)

### Run locally

```bash
go run ./cmd/server
```

Server listens on `:2001` by default. Override with the `PORT` environment variable:

```bash
PORT=3000 go run ./cmd/server
```

The SQLite database is stored as `jembom.db` in the working directory. Override with `DB_PATH`:

```bash
DB_PATH=/data/jembom.db go run ./cmd/server
```

### Deploy to Fly.io

```bash
fly volumes create jembom_data --size 1 --region iad -a jembom
fly deploy
```

## Tech Stack

- **Language:** Go
- **Protocol:** Telnet (raw TCP, ANSI escape codes)
- **Database:** SQLite via `modernc.org/sqlite`
- **Rendering:** Delta rendering — only changed cells are sent to the client each tick
- **Deployment:** Fly.io
